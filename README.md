# Hadiqa Aamir — Portfolio

Independent portfolio website for Hadiqa Aamir, a Toronto-based product designer working across AI-enabled healthcare products, visual communication, and design-to-development.

## Current structure

- Product design leads the homepage narrative.
- Three case-study directions establish the core body of work.
- Visual communication and art share the same editorial design system.
- The site is dependency-free and ready for free static hosting on Vercel.

## Local preview

Open `index.html` directly, or serve the repository with any static file server.

## Deployment

Import this repository into Vercel as a static project. Connect `hadiqaaamir.com` only after the design and content have been approved.
